## C++ 模板高级特性与底层思维学习笔记

### 💡 核心认知：模板的本质

在深入语法之前，必须建立起编译器视角的宏观思维：

- **模板不是类型，是“图纸”**：`std::vector` 是一张图纸（模板），`std::vector<int>` 才是根据图纸造出来的成品（类型）。
- **鸭子类型与契约机制**：模板声明只是在规定“形状”和“签名”（比如需要几个参数），它不关心具体传入的是什么，只要形状匹配（符合契约），编译器就会放行。
- **实例化（Instantiation）机制**：模板代码在未被调用前不会生成任何机器码。只有在传入具体类型（如 `int`）时，编译器才会进行“文本替换”，真正在内存中具现化出一个具体的类或函数。

------

### 一、 模板的模板参数 (Template Template Parameter)

**1. 语法与应用场景**

当我们需要在模板内部灵活组合不同的“容器”和“数据”时，使用模板的模板参数可以将它们解耦。

C++

```
template <template <typename, typename> class Container, typename T>
class Wrapper {
    Container<T, std::allocator<T>> data;
};
```

**2. 深度解析**

- `class Container`（或 `typename Container`）：在这里，`Container` 不是一个具体类型，而是一个**模板的代号**（比如 `std::vector`）。
- `<typename, typename>`：这是对 `Container` 这张图纸的**形状约束**，表示传入的模板必须自带两个类型参数。
- **为什么能传 `std::vector`？** 因为 `std::vector` 底层实际为 `template <typename T, typename Allocator = std::allocator<T>>`，天生带有两个参数，完美契合上述坑位。同样，`std::list`、`std::stack` 也符合此特征。

------

### 二、 匿名模板参数 (无名 `typename`)

**1. 为什么可以省略名字？**

就像函数声明可以只写 `void process(int, double);` 一样，在编译器只需要确认“参数个数和种类”的上下文中，给参数起名字是多余的。`template <typename, typename>` 中的 `typename` 仅仅是**占位符**。

**2. 常见的三种合法场景**

- **声明模板的模板参数**：如上述 `Container` 的签名约束，只需关注形状，无需在当前作用域使用。

- **模板前向声明**：`template <typename, typename> class MyPair;`，仅告诉编译器存在这样一个需要两个参数的模板类。

- **SFINAE 与类型限制 (高级玩法)**：充当条件检查的“门卫”。

  C++

  ```
  template <typename T, typename = std::enable_if_t<...>> // 第二个参数无名
  void func(T val) {}
  ```

------

### 三、 模板特化 (Template Specialization)

模板特化本质上是**基于类型的模式匹配**，类似函数重载，但针对的是类型参数。当默认的通用图纸无法满足特定类型的需求时，我们可以提供专用的图纸。

#### 1. 全特化 (Full Specialization)

所有模板参数均被指定为具体类型。

- **语法标志**：`template <>`。因为所有的坑位都被填满了（如 `int`, `double`），**没有任何未知数需要推导**，所以尖括号内为空。

- **核心特性**：特化版本的内部实现**可以与通用版本完全无关**。它不需要保留原有的成员变量或方法。

  > **经典案例**：标准库中的 `std::vector<bool>` 就是一个全特化版本，它为了节省内存，底层改用 bit（位）来存储，与普通的 `std::vector<T>` 在内存结构和方法返回值上截然不同。

C++

```
// 通用模板
template <typename T> class MyBox { T data; };

// 全特化
template <> class MyBox<void> { void completelyDifferentMethod(); };
```

#### 2. 偏特化 (Partial Specialization)

*注意：仅类模板支持偏特化，函数模板不支持（函数模板通常通过重载来达到类似效果）。*

当只指定了一部分模板参数，或者对参数的类型特征（如指针、引用）进行了限制时使用。

- **语法标志**：`template <typename T>` 等。因为特化后**仍然存在未知的、需要编译器推导的类型参数**，所以必须在最前面的 `< >` 中将这些“未知数”注册声明出来。

C++

```
// 通用模板（两个未知数 T, U）
template <typename T, typename U> class Pair { ... };

// 偏特化（锁死第二个为指针类型，但 T 和 U 仍是未知数，需要声明注册）
template <typename T, typename U> class Pair<T, U*> { ... };

// 偏特化（锁死第一个为 int，只剩 U 是未知数，仅声明 U）
template <typename U> class Pair<int, U> { ... };
```

------

### 🚀 进阶心法总结

下次写模板或者看别人的“模板天书”时，只需问自己三个问题：

1. **这是在定契约（声明形状），还是在拼装（实例化类型）？**
2. **这里的坑位（尖括号里的未知数），有几个是需要编译器去推导的？**（决定了 `template <...>` 里面写什么）。
3. **我是要用通用图纸，还是要为某个特殊类型撕掉图纸重写？**（决定了是否使用特化）。
